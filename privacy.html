Muse 개인정보처리방침

최종 업데이트: 2026년 10월 11일

이 방침은 운영자 본인의 개인용 Muse 봇이 Google 및 Telegram 정보를 어떻게 처리하는지 설명합니다.

접근하는 정보

Telegram 개인 채팅의 사용자 식별자와 텍스트 요청을 처리합니다. Google 계정에서 승인한 권한에 따라 Gmail 메일 ID, 제목, 발신자, 날짜, 라벨, 미리보기와 요청한 본문에 접근합니다. 첨부파일 다운로드는 지원하지 않습니다. Google OAuth 접근·갱신 토큰은 인증 유지를 위해 저장합니다.

이용 목적과 변경

정보는 사용자가 요청한 메일 검색, 읽기, 요약, 답장 문안 작성 및 승인한 메일 정리에 사용합니다. 보관·라벨 추가·초안 저장은 미리보기 후 별도 승인이 있어야 실행됩니다. 이 버전의 봇은 메일 발송이나 삭제를 지원하지 않습니다.

전달되는 정보

AI 응답에 필요한 사용자 요청, 최근 대화와 조회한 메일 정보는 OpenAI의 Codex 모델에 전달됩니다. 답변과 변경 미리보기는 Telegram으로 전달됩니다. Google OAuth 토큰과 Telegram 봇 토큰은 모델 입력에 포함하지 않습니다. 제공업체의 데이터 처리는 해당 계정 설정 및 Google, OpenAI, Telegram의 정책을 따릅니다. 봇 운영자는 메일 데이터를 판매하거나 광고 목적으로 사용하지 않습니다.

보관과 보호

인증과 운영 데이터는 사용자가 관리하는 서버의 앱 데이터 영역에 저장됩니다. 최근 대화는 최대 8회 대화 범위로 제한하고, 모델에 보내는 최근 문맥은 최대 30,000자입니다. 메일 조회 증거 캐시는 24시간 후 정리됩니다. 완료한 요청 기록은 24시간 후, 발송 완료한 대기 메시지는 주기적으로 정리합니다. 오래된 승인 기록도 정리합니다. 미완료 작업과 유효한 인증은 운영에 필요한 동안 유지됩니다. 삭제된 SQLite 기록은 저장장치의 완전 삭제를 뜻하지 않습니다. PC에서 승인할 때 생성한 인증 사본은 운영자가 별도로 관리합니다.

연결 해제와 삭제

Google 계정의 서드파티 연결 관리에서 Muse의 접근 권한을 해제할 수 있습니다. 봇의 /new 명령은 최근 대화와 조회 캐시를 초기화하고 대기 중 변경을 취소합니다. 전체 데이터와 인증 사본 삭제는 서버 운영자가 봇을 중지한 뒤 수행합니다.

문의 및 홈페이지

개인용 앱이므로 문의와 데이터 삭제 요청은 앱 운영자에게 직접 전달합니다. OAuth 동의 화면의 사용자 지원 이메일이 연락 창구입니다. 이 안내 홈페이지에는 분석 스크립트나 데이터 입력 폼이 없습니다. GitHub Pages에서 게시될 경우 호스팅 제공업체가 보안 목적으로 방문 IP를 기록할 수 있습니다.
