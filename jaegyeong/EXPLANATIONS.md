# 문항별 정답 해설 · 풀이

2026-10-12에 재무·세무·원가 각 10개, 총 30개 문항의 학습용 해설을 작성했습니다. 정답 이유, 단계별 계산·판단, 네 보기의 설명, 관련 개념, 출처·검토 상태를 제공합니다. 전체 4,321개 학습 가능 문항의 해설을 작성한 것은 아닙니다.

## 학습 화면

- 홈의 **해설 30문항 풀기**는 작성된 문항만으로 세션을 만듭니다. 기존 학습이 진행 중이면 기존과 같은 세션 대체 확인을 거칩니다.
- **문제 둘러보기 → 해설 있는 문제만**에서 과목별로 좁히거나 선택 목록을 풀 수 있습니다. 목록은 기존처럼 20개씩 표시합니다.
- 퀴즈에서는 답을 채점한 뒤 해설이 펼쳐집니다. 채점 전에는 해설 본문을 렌더링하지 않습니다.
- 오답 노트·즐겨찾기·문제 목록의 **해설**은 기록을 추가하지 않고 열람합니다. 미리보기의 해설은 접힌 상태로 제공하며, 학습자가 직접 열면 정답을 확인할 수 있습니다.
- 해설이 없는 문항은 **준비 중**으로 표시하고 기존 관련 개념을 사용할 수 있습니다. 같은 유형의 다른 수치 해설을 대신 보여주지 않습니다.

## 작성·검토 범위

모두 AI 작성 학습용 해설입니다. 삼일회계법인의 공식 해설이 아니며 전문가 검수는 아직 받지 않았습니다. 문항 원본 이미지 30개를 확인했고, 저장소의 공식 답안 배열과 해설 결론을 대조했습니다. 수치 계산은 안전한 산술 평가기로 자동 검산합니다.

| 범위 | 검토 상태 | 대조 내용 |
|---|---|---|
| 세무 10개 | `source_checked` | 적용 연도 2025/2026의 법령 원문 보존본, 문제의 세법 연도·가정, 계산 검산 |
| 원가 10개 | `source_checked` | OpenStax 공개 교재의 설명·수식 이미지 alt 텍스트, 문제별 계산 검산 |
| 재무 10개 | `partial` | 기존 개념 노트·공식 정답·문항 조건, 계산 검산. K-IFRS 원문 직접 재대조 필요 |

이번 환경에서는 한국회계기준원 목록의 직접 접근이 403으로 제한되었습니다. 재무 해설의 기준서 출처를 새로 확인했다고 기록하지 않았습니다. 실제 읽은 자료인 기존 개념 노트를 출처로 기록하고, 기준서 재대조가 필요한 범위를 `unchecked_points`에 분리했습니다. 라이선스·용역형 보증·고객에게 지급하는 대가처럼 기존 노트보다 상세한 내용도 미대조로 명시했습니다.

세법은 `legalize-kr/legalize-kr`의 국가법령정보센터 OpenAPI 보존 자료를 사용했습니다. 각 출처에 실제 읽은 커밋·시행일·공포번호·파일 링크를 남겼습니다. 앞으로 시행될 법령 판본을 현재 연도에 적용하지 않습니다. 소득세법 제17조의 11% 배당가산 개정은 법률 제21221호 부칙 제14조의 경과규정을 함께 확인했습니다. 수록 문제의 10% 가정 및 적용 연도를 따릅니다. 직접 대조한 법령 판본은 `data/explanations.json`의 `sources`가 기준입니다.

원가는 `openstax/osbooks-principles-accounting-bundle`의 실제 읽은 커밋을 출처 링크에 고정했습니다. 공개 교재의 라이선스는 CC BY-NC-SA 4.0이며, 원문 설명·예제를 옮겨 싣지 않고 해당 기출 조건으로 풀이를 작성했습니다. 원문 PDF나 외부 교재 파일을 저장소에 추가하지 않았습니다.

## 원본과 생성 절차

`data/explanations.json`이 편집 원본입니다. `schema_version: 1`이며 `sources`에 실제 대조 자료의 정보, `items`에 해설을 저장합니다. 주요 필드는 다음과 같습니다.

- `question_id`: 기존 `entries.json`의 문항 ID. 출제 이력·유형 그룹으로 자동 상속하지 않습니다.
- `question_fingerprint`: ID·본문·보기·공식 답안·적용 세법 연도의 SHA-256입니다. 정규화 없이 원문 데이터를 기준으로 합니다.
- `answers`, `tax_law_year`, `part_id`: 공식 답안·원문 연도·관련 개념 연결입니다.
- `summary`, `steps`, `option_notes`: 해설 결론, 단계별 풀이, 네 보기의 설명입니다. `is_answer`는 시험에서 선택해야 하는 보기인지 뜻하며, 문장 자체가 옳다는 뜻이 아닙니다.
- `checks`: 검산식과 예상 결과입니다. 가격차이 등은 양수 불리/음수 유리, 증분손익은 양수 증가/음수 감소로 작성합니다.
- `sources`, `review_status`, `review_note`, `unchecked_points`, `authorship`, `checked_on`: 출처·검토 범위·미확인 내용·작성 구분·확인일입니다.

`scripts/explanation_data.py`가 연결을 검증하고 `build_app_data.py`가 생성 번들의 `explanations`에 포함합니다. 원문이나 답안을 바꾸면 재검토 없이 이전 해설을 배포하지 못하도록 빌드가 실패합니다. 이를 해제하려고 해시만 덮어쓰지 마세요. 원문 이미지·확정답안·적용 연도·계산을 확인하고 해설과 검토 기록을 함께 수정한 뒤 `question_fingerprint(q)`로 해시를 갱신하세요.

```sh
python jaegyeong/scripts/build_app_data.py
python jaegyeong/scripts/test_bank.py
python jaegyeong/scripts/test_parts.py
python jaegyeong/scripts/test_concepts.py
python jaegyeong/scripts/test_explanations.py
# 저장소 루트를 HTTP로 제공한 뒤 실행
python jaegyeong/scripts/test_app.py
python jaegyeong/scripts/test_browser.py
python jaegyeong/scripts/test_explanations_app.py
```

루트 사이트, 기존 문항 데이터·ID·정답, `chagok.study.v1` 저장 형식은 이 기능에서 변경하지 않았습니다. 해설 열람 자체는 시도 횟수·오답 상태·세션 위치를 바꾸지 않습니다. 해설 세트 풀이의 채점은 기존과 동일하게 기록합니다.
