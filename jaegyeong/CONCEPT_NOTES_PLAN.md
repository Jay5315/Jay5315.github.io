# 추가 요청: 파트별 핵심 개념과 학습 팁

사용자 요청: "문제 은행 말고도 해당 파트 및 관련 중요한 팁이나 개념 등을 알려줄 수 있으면 좋겠다."

이 문서는 처음 받은 요구사항입니다. **구현 현황(2026-10-12):** 화면·연결·데이터 구조를 모두 구현했고 74개 파트 중 15개에 노트를 작성했습니다(세무 6 원문 대조, 원가 5 계산 검증, 재무 4 출처 확인 필요). 나머지 59개는 '준비 중'으로 표시합니다. 세부 상태는 README의 '개념 노트'를, 다음 작업은 HANDOFF.md를 보세요.

## 사용 흐름

1. 홈에서 과목·파트를 고르면 해당 파트의 핵심 개념을 먼저 볼 수 있습니다.
2. 파트별 노트에 핵심 개념, 필요한 경우 계산 공식, 자주 틀리는 포인트, 관련 파트를 제공합니다.
3. 문제 풀이 화면의 "관련 개념"에서 같은 노트를 열 수 있습니다. 현재 문제의 답을 미리 표시하는 개별 해설과는 구분합니다.
4. 오답 복습에서도 문제의 주 파트 또는 보조 태그에 맞는 개념으로 이동할 수 있습니다.
5. 노트에서 "이 파트 문제 풀기"로 현재 문제은행 학습 세트를 시작합니다.

## 노트 내용

- **핵심 개념:** 용어 정의, 왜 필요한지, 판단 순서를 짧고 정확하게 설명합니다.
- **계산 공식:** 공식뿐 아니라 변수의 뜻·단위·적용 조건을 같이 씁니다. 공식이 없는 이론 파트에는 억지로 넣지 않습니다.
- **자주 틀리는 포인트:** 부정형 질문, 금액의 기준, 기간, 손익/자본 구분 등 실질적인 혼동을 설명합니다. 근거 없이 출제 빈도나 중요도를 숫자로 단정하지 않습니다.
- **짧은 예시:** 원문 기출의 정답을 유출하지 않는 별도 예시를 사용할 수 있습니다. 예시 수치의 계산을 확인합니다.
- **관련 개념:** `taxonomy.json`의 다른 파트 ID 및 기존 보조 태그를 연결합니다.
- **근거·적용 기준:** 출처, 적용 연도/기준, 검토 상태를 보존합니다.

주 파트 74개를 한 번에 억지로 채우기보다 몇 개 파트로 화면과 내용 수준을 확인한 뒤 늘릴 수 있습니다. 미작성 파트는 "준비 중"으로 표시하고 빈 설명이나 생성 오류를 학습 사실처럼 노출하지 않습니다.

## 연도와 정확성

세무회계의 한도·세율·공제 요건은 연도에 따라 바뀔 수 있습니다. 문항의 `tax_law_year`와 노트의 적용 기준이 다르면 구분해서 보여 주세요. 2026년 1·3월 문항에는 2025년 세법이 지정되어 있다는 기존 예외를 유지합니다.

회계기준도 변경될 수 있으므로 특정 기준이나 회계처리를 설명할 때 적용 기준을 확인합니다. 현재 PDF는 문제·공식 답안 자료이며 공식 해설이나 완성된 학습 이론집이 아닙니다. 문제에서 추측한 내용을 공식 해설로 표기하지 말고, 확인 가능한 회계기준·법령·공식 자료 또는 사용자가 제공한 교재를 근거로 작성하세요. 확인하지 않은 출처나 링크를 만들지 마세요.

과거 문제 기준의 설명과 현행 기준의 설명을 혼합하지 마세요. 확인하지 못한 내용은 검토 필요 상태로 남깁니다. 개별 문제 풀이 해설은 이 파트별 노트와 별도의 후속 범위입니다.

## 구현 제안

- `data/concept-notes.json`을 편집 가능한 원본으로 두고 파트 ID를 키로 연결합니다.
- 제안 필드: `id`, `part_id`, `title`, `summary`, `key_points`, `formulas`, `pitfalls`, `examples`, `related_part_ids`, `tags`, `applicability`, `sources`, `review_status`.
- `applicability`는 연도와 적용 기준을 표현하며, 미확인 연도를 현재 연도로 자동 채우지 않습니다.
- `sources`는 자료명과 확인 가능한 위치/URL을 담습니다. 실제로 읽고 검증한 자료만 포함합니다.
- `build_app_data.py`에서 노트를 웹앱 번들에 포함하면 현재의 정적 웹앱 구성을 유지할 수 있습니다.
- `assets/app.js`에서 홈·풀이·오답 화면에 진입점을 추가합니다. 문항별 정답 표시, 기존 세션과 로컬 저장 형식은 보존합니다.
- 파트 분류 검토 중인 문항은 관련 노트가 잠정 연결임을 알 수 있게 합니다.

## 완료 기준

- 노트가 있는 파트와 미작성 파트 모두 오류 없이 표시됩니다.
- 문제의 주 파트와 노트 연결이 일치하고, 관련 파트 이동 및 해당 파트 학습 시작이 됩니다.
- 모바일에서 수식·표·긴 문장이 읽히며 닫기 후 풀이 위치·선택 상태가 유지됩니다.
- 세법 적용 연도가 다른 문제와 노트를 구분합니다.
- 각 노트에 내용 검토·출처 확인 상태를 남깁니다. 검증하지 않은 이론의 정확성을 테스트 통과만으로 주장하지 않습니다.
- 기존 채점·복수 정답·오답·즐겨찾기·이어 풀기·백업 복원 검사를 유지합니다.
