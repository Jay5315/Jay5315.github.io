차곡 — 재경관리사 문제은행

[PC에서 ZIP으로 시작하기]
1. ZIP 파일을 모두 압축 해제하세요.
2. index.html을 Chrome 또는 Edge로 여세요.
3. 과목과 파트, 문제 수를 고르고 학습을 시작하세요.

index.html만 따로 옮기면 문제가 표시되지 않습니다.
assets, images, sources 폴더를 함께 두세요.

[휴대폰·웹에서 시작하기]
휴대폰이나 PC의 브라우저에서 아래 주소로 바로 열 수 있습니다.
https://jay5315.github.io/jaegyeong/
처음에는 인터넷에 연결해 접속하세요. 한 번 접속해 '오프라인 준비 완료'가 표시되면
문제 텍스트와 해설은 인터넷 없이도 열 수 있습니다.
원본 이미지·PDF는 최근에 온라인으로 연 자료만 일부 저장됩니다.

[학습 기능]
· 학습 홈 / 개념 노트 / 문제 둘러보기
· 오답 노트 / 즐겨찾기 / 학습 기록
· 해설 4,281문항 풀기 / 정답 확인 / 정답 해설 · 풀이 보기
· 오늘 복습 / 이어서 풀기
· 원본 이미지 / 원본 PDF / 기록 백업·복원

학습 기록은 사용 중인 브라우저에 저장합니다.
다른 브라우저나 기기로 이동하기 전에 '기록 백업·복원' 또는
우측 상단 '나' 버튼에서 기록을 백업하세요.

브라우저가 파일 실행을 제한하는 환경이라면 폴더에서 HTTP 서버로 실행할 수 있습니다.
Python이 설치된 PC: python -m http.server 8001
실행한 뒤 브라우저에서 http://localhost:8001/ 을 여세요.

제공된 문제와 공식 답안을 보존했으며, 정답 해설 4,281문항을 포함합니다.
출처 확인 4,169문항·부분 확인 112문항이며, 부분 확인 해설에는 남은 의문을 표시합니다.
AI 작성 학습용 해설 · 삼일회계법인의 공식 해설 아님
텍스트의 표·수식·도표가 불명확하면 원본 이미지와 PDF를 확인하세요.
