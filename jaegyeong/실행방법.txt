차곡 — 재경관리사 문제은행

[PC에서 시작하기]
1. ZIP 파일을 모두 압축 해제하세요.
2. index.html을 Chrome 또는 Edge로 여세요.
3. 과목과 파트, 문제 수를 고르고 학습을 시작하세요.

index.html만 따로 옮기면 문제가 표시되지 않습니다.
assets, images, sources 폴더를 함께 두세요.

[학습 기능]
· 74개 파트별 학습 / 파트별 핵심 개념 노트 / 문제 검색 / 정답 확인
· 오답 노트 / 즐겨찾기 / 이어 풀기 / 결과 기록
· 읽기 편한 텍스트 / 원본 이미지 / 문제 확대
· 기록 백업·복원

학습 기록은 사용 중인 브라우저에 저장합니다.
다른 브라우저나 기기로 이동하기 전에 우측 상단 '나' 버튼에서 기록을 백업하세요.
휴대폰에서 웹 주소로 접속하려면 별도 웹 호스팅이 필요합니다.

브라우저가 파일 실행을 제한하는 환경이라면 폴더에서 HTTP 서버로 실행할 수 있습니다.
Python이 설치된 PC: python -m http.server 8001

제공된 문제와 공식 답안을 보존했습니다. 해설은 포함하지 않았습니다.
텍스트의 표·수식·도표가 불명확하면 원본 이미지와 PDF를 확인하세요.
