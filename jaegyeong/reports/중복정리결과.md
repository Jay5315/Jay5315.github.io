# 재경관리사 문제은행 중복 정리 결과

2022년 1월부터 2026년 9월까지 제공된 38회분을 처리했습니다. 원본 4,560문항은 모두 보존하고, 문제은행 표시 목록에서 확정 중복을 통합했습니다.

## 통합 기준

- 공백·줄바꿈과 검증한 일부 문구 차이를 정규화하되 숫자, 단위, 부정 표현, 연산 기호는 보존합니다.
- 질문·자료·보기 내용이 같고 공식 정답의 보기 내용도 일치할 때 통합합니다. 보기 순서만 다른 경우에도 문제·보기·정답을 대표 원문의 한 세트로 사용합니다.
- 보기 안에서 다른 보기 번호를 참조하는 문제는 보기 순서를 임의로 바꾸지 않습니다.
- 표는 좌표 기반 읽기 순서로 처리하며, 도표·그림은 그래픽 정보도 일치해야 자동 통합합니다.
- 같은 내용 중 검토 표시가 적은 최신 회차를 대표로 택하고 모든 원본 출처와 해당 회차의 정답을 유지합니다.
- 숫자만 달라지고 나머지 문구·조건이 동일한 문제는 변형으로 묶되 각각의 원문과 정답을 보존합니다. 세무회계 변형은 적용 세법 연도를 함께 고려합니다.
- 문자 유사도는 후보 검색에만 사용했습니다. 부정 표현이나 핵심 보기 변경이 있을 수 있는 후보는 자동 통합하지 않았습니다.

## 실제 확인 사례

- 2022년 6월·9월 재무회계 1번: 보기 순서와 정답 번호(①/④)가 다르지만 같은 내용이므로 통합.
- 2023년 9월·12월 재무회계 1번: 보기 순서만 다르므로 통합.
- 2024년 7월·2025년 7월 재무회계 1번: 공정가치 적용 확대의 표현 차이를 확인하고 통합.
- 2024년 6월·11월 재무회계 1번: 판단하는 지식이 달라 별도 유지.
- 2023년 6월·2024년 6월 재무회계 5번: 문자 유사도는 매우 높지만 부정 표현과 정답이 달라 별도 유지.
- 2022년 1월·2023년 9월 전체 105번: 수치가 다른 영업레버리지 문제를 같은 변형 그룹으로 연결.

## 원본 및 추출 특이사항

- **2024년 9월 전체 63번(세무회계 23번): 원본 PDF 26쪽에 선택지가 ①~③만 표시됩니다.** 다음 페이지에도 ④가 없는 것을 확인했습니다. 문항을 임의로 복원하지 않고 기본 풀이 목록에서 보류했습니다.
- **2026년 7월 재무회계 26번: 공식 확정답안은 ① 또는 ④입니다.** 두 답 모두 정답으로 채점합니다.
- **2026년 1월·3월 세무회계: 원문이 지정한 적용 세법은 2025년입니다.** 2026년 5월부터는 원문에 2026년 세법으로 표시됩니다. 시험 연도와 별도로 저장했습니다.
- 전 문항을 PDF의 위치로 잘라 원본 이미지로 보존했습니다. 전 문항의 원본 PDF·페이지·선택 정답에 접근할 수 있습니다.
- 수식용 글꼴 때문에 검색 텍스트에 전용 문자 코드가 있는 5문항은 이미지로 표시하고 자동 중복 통합에서 제외했습니다.

## 검증 범위와 남은 작업

- 4,560개 원본이 통합 항목에 정확히 한 번씩 연결되는지, 회차별 120문항·정답·과목 경계, 이미지/PDF 파일 존재 여부를 검증했습니다.
- 보기 순서 변경, 부정 표현 변경, 수치 변형, 복수 정답, 적용 세법, 보류 문항을 대상으로 회귀 테스트 10개를 실행했습니다.
- 브라우저에서 검색, 대표·변형 전환, 복수 정답 채점, 보류 문항 처리, 유사 후보 비교, 모바일 너비를 검증했고 오류가 없었습니다. 전 문항의 텍스트가 이미지 자르기 영역 밖으로 잘리지 않는지도 좌표로 확인했습니다.
- 이 결과는 **확정 가능한 중복을 제거한 보수적인 정리본**입니다. 모든 의미상 중복까지 제거됐다는 뜻은 아닙니다. 유사 후보는 `data/review-candidates.json`과 검토 화면에 남겼습니다.
- 과목별 분류는 되어 있으나 세부 파트 분류, 해설 작성, 전 문항의 표·도표 육안 검수 및 최신 법령 기준 재검증은 아직 수행하지 않았습니다.
- 현재 화면은 이 자료를 검토하기 위한 로컬 화면입니다. 외부 공개·배포는 수행하지 않았습니다.

## 파일

- `data/questions.json`: 원본 4,560문항, 정답, 이미지, 출처, 적용 세법, 검토 표시
- `data/entries.json`: 중복 통합 후 대표와 모든 출제 이력
- `data/families.json`: 유형별 대표와 수치 변형 연결
- `data/review-candidates.json`: 자동 통합하지 않은 유사 후보
- `reports/출처와중복매핑.csv`: 원본문항 → 대표문항 → 유형그룹 매핑
- `sources/`, `images/`: 원본 PDF 복사본과 문항별 원본 이미지
