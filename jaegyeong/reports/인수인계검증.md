# GitHub 인수인계 검증 기록

## 이번 저장 범위

기존 실행 웹앱에 다음 자료를 추가했습니다.

- `data/`: 원본문항·중복/변형 관계·파트 분류·검토 대상·출처 목록
- `scripts/`: 추출부터 웹앱 번들까지 재생성, 데이터 검사, 브라우저 검사, ZIP 생성
- `reports/`: 기존 검토 결과·CSV·확인용 스크린샷
- `research/intake/`: 초기 업로드 목록·추출 텍스트·회차 확인 기록
- `README.md`, `HANDOFF.md`, `AGENTS.md`: 실행·개발·검증·배포·주의사항
- `CONCEPT_NOTES_PLAN.md`: 사용자가 다음 AI에게 맡기기로 한 개념·팁 기능 요구사항 (미구현)

재현에 불필요한 중복 추출 캐시·가상환경·임시 백업·테스트 산출물·대용량 ZIP은 Git에서 제외합니다. 원본 PDF와 이미지는 기존 커밋에 이미 있습니다.

## 재생성 검증

저장소의 `jaegyeong/`으로 자료를 옮기고, `/workspace/exam-review`에 의존하던 초기 추출 대체 경로를 제거했습니다. 필수 입력은 `data/source-exams.json`과 저장소 내 PDF입니다.

`python jaegyeong/scripts/build_bank.py` 실행 후 다음 6개 파일의 SHA-256이 실행 전과 모두 같았습니다.

- `data/questions.json`
- `data/entries.json`
- `data/families.json`
- `data/summary.json`
- `data/classification-summary.json`
- `assets/bank-data.js`

이는 기존 추출 문항을 입력으로 중복·변형·분류·웹앱 번들을 재생성한 검증입니다. 이번 인수인계 작업에서 모든 PDF를 `--reextract`로 다시 추출하지는 않았습니다.

## 테스트

- `test_bank.py`: 10개 통과
- `test_parts.py`: 5개 통과
- `test_app.py`: 실제 저장소의 `/jaegyeong/` 경로에서 기능·새로고침·기록 복원·복수 정답·오답·백업·모바일 확인 통과
- `test_browser.py`: 보존한 자료 검토 화면의 필터·비교·변형·보류·모바일 확인 통과
- 테스트 중 브라우저 JavaScript 오류 없음
- `package_app.py`: 실행용/전체 작업 ZIP의 CRC와 모든 문항 이미지·PDF 포함 검사 통과

테스트 주소는 `APP_BASE_URL`로 설정하며 테스트 출력은 Git에서 제외한 `_artifacts/`에 저장됩니다. 개인 사용자의 브라우저 저장소나 실제 학습 기록은 테스트·저장 범위에 포함하지 않았습니다.
