# 차곡 웹앱 검증

## 구현

- 독립적인 정적 웹앱: 외부 API·로그인·CDN·빌드 도구 없이 HTML/CSS/JavaScript 사용
- 원문 4,560문항에서 중복 정리한 4,322항목, 학습 가능한 4,321항목, 기본 대표 4,144항목
- 74개 주 파트, 보조 태그, 분류 검토 표시, 수치 변형 포함 여부
- 학습 세트, 문제별 채점, 오답 재풀이, 즐겨찾기, 이어 풀기, 세션 결과
- 브라우저 기록 저장 및 JSON 백업·확인 후 복원
- 원본 이미지, 확대 보기, 모바일 텍스트 보기, PDF와 확정답안 연결
- 도표·특수 폰트 문항은 원본 이미지 표시

## 통과한 검사

- 기존 중복·답안·출처 회귀 테스트 10개
- 파트 분류·태그·출처 상속 검사 5개
- 보존한 자료 검토 화면의 검색·필터·복수 정답·변형·보류·비교·모바일 검사
- 새 학습 웹앱: 과목/파트/문항 수/분류 검토 제외, 채점, 새로고침 후 상태 복원, 이어 풀기, 미응답 종료
- 틀린 문제 재풀이 후 오답 해제, 누적 시도 유지, 즐겨찾기, 문제 검색
- 2026-07-026의 공식 정답 ① 및 ④ 각각 인정, 2024-09-063 학습 제외
- 실제 JSON 백업 다운로드, 잘못된 파일 거부, 확인창 이후 복원
- 키보드 1~4/Enter 조작, PC 1440px 및 모바일 390px, 텍스트/원본 전환·확대
- JavaScript 문법 및 브라우저 실행 오류 없음
- ZIP CRC 및 데이터가 참조하는 모든 이미지·PDF의 포함 여부 확인

브라우저 검증은 이 환경의 Chromium에서 로컬 HTTP로 수행했습니다. 환경의 관리 정책이 file:// 탐색을 차단하여 이 환경에서 더블클릭 실행을 직접 검증하지는 못했습니다. 메인 앱에는 fetch, 모듈 로딩, 서비스 워커 등 파일 실행 시 서버를 요구하는 기능을 사용하지 않았으며 일반 스크립트 번들로 구성했습니다. 외부 호스팅·배포와 실제 휴대폰 OS의 파일 열기는 수행하지 않았습니다.

브라우저 저장소는 기기·브라우저·주소별로 분리됩니다. 저장 실패는 화면에서 알리고 현재 메모리의 기록을 백업할 수 있습니다. 해설과 최신 법령에 맞춘 정답 재검증은 이번 작업에 포함하지 않았습니다.
