# 실제 기기 최종 점검

대상: https://jay5315.github.io/jaegyeong/

이 문서의 빈 체크박스는 **아직 실제 기기에서 확인하지 않은 항목**입니다. 로컬 Chromium의 모바일 화면 모사·키보드·백업 이전 검사는 통과했지만 실제 휴대폰, Safari, NVDA·VoiceOver·TalkBack의 음성 출력을 확인한 결과는 아닙니다. 자동 점검 범위와 환경 제한은 [검증 기록](reports/user-journey-validation.json)에 있습니다.

테스트에는 새 브라우저 프로필을 쓰거나, 먼저 오른쪽 위 **나 → 기록 백업**으로 현재 기록을 저장하세요. 백업 복원은 확인 버튼을 누르면 현재 브라우저의 기록을 바꿉니다.

## 1. 실제 PC·휴대폰

PC 브라우저 한 종류와 실제 휴대폰에서 각각 확인합니다. 기종·OS·브라우저 버전을 아래 기록란에 남깁니다.

- [ ] 홈에서 재무회계·10문제를 골라 학습을 시작합니다. 누른 과목·문제 수가 그대로 선택됩니다.
- [ ] 보기를 고르고 **정답 확인**을 누릅니다. 정답·선택한 보기·풀이·보기별 설명을 읽을 수 있습니다.
- [ ] **관련 개념**을 열었다 닫습니다. 선택한 답·채점 결과·문항 위치가 유지됩니다.
- [ ] **나중에 이어 풀기 → 이어서 풀기**로 돌아옵니다. 새로고침해도 채점된 답과 진행 위치가 유지됩니다. 채점 전 선택만 한 답은 저장 대상이 아닙니다.
- [ ] 한 문제를 틀린 뒤 학습을 마칩니다. **오답 노트**에서 그 문제를 다시 맞히면 최신 오답 목록에서 빠집니다.
- [ ] 문제에 별을 눌러 **즐겨찾기**에서 확인합니다. 미리보기 안에서 별을 해제하고 닫으면 목록 화면을 계속 조작할 수 있습니다.
- [ ] **문제 둘러보기**에서 `2024-11 1번`을 검색하고 재무회계를 선택합니다. 해당 회차·과목의 1번 한 문항을 찾습니다.
- [ ] **나 → 글자 크기 → 아주 크게**와 밝은/어두운 테마에서 문항·해설·개념 노트를 읽습니다. 화면 전체가 옆으로 밀리지 않고 닫기·채점 버튼을 누를 수 있습니다. 넓은 표·원본 이미지는 해당 영역 안에서 가로로 움직일 수 있습니다.
- [ ] 실제 휴대폰을 가로·세로로 돌립니다. 같은 문항을 유지하고 하단 채점·다음 문제 버튼이 다른 메뉴에 가려지지 않습니다.
- [ ] 검색 중 실제 화면 키보드를 열고 닫아도 검색칸·필터·미리보기·채점 버튼을 조작할 수 있습니다.

## 2. 키보드·화면낭독기

PC는 NVDA+Chrome/Edge 또는 VoiceOver+Safari, 휴대폰은 VoiceOver+Safari 또는 TalkBack+Chrome 중 사용 가능한 조합에서 확인합니다. 각 조합의 실제 결과를 따로 기록합니다.

- [ ] 키보드 `Tab`으로 문제 수·과목 버튼에 이동해 `Enter`를 두 번 누릅니다. 초점이 같은 버튼에 남고 다른 값으로 바뀌지 않습니다. 과목 카드는 같은 버튼을 다시 누르면 선택 해제되는 원래 동작입니다.
- [ ] 개념 노트의 과목 필터와 풀이의 **텍스트로 읽기/원본 이미지**도 같은 방식으로 확인합니다.
- [ ] 미리보기의 **개념** 버튼과 개념 창의 다른 탭을 실행합니다. 초점이 새 창 내용 안의 닫기 버튼 또는 선택된 탭으로 이동합니다.
- [ ] `Escape`로 창을 닫으면 창을 열었던 버튼으로 돌아옵니다. 즐겨찾기 해제로 그 버튼이 사라진 경우에는 결과 목록으로 돌아옵니다.
- [ ] 숫자 `1`~`4`로 보기를 고르고 **정답 확인**을 실행합니다. 화면낭독기가 정오답·공식 정답을 한 번 알립니다. 버튼에 초점이 있으면 `Enter`는 해당 버튼을 실행합니다.
- [ ] 채점 뒤 해설이 늦게 나타나거나 표시 방식을 바꾸어도 같은 채점 결과를 다시 알리지 않습니다. 다음 문항에서 같은 정답을 다시 채점하면 새 결과로 알립니다.
- [ ] 검색칸에서 한글을 입력합니다. 조합 중 매 글자마다 끼어들지 않고 입력을 멈추면 최종 결과 개수를 알립니다. 과목·파트·해설 필터를 바꿔도 최종 개수를 알립니다.
- [ ] 표시된 초점 윤곽을 항상 찾을 수 있고 키보드만으로 학습 시작·채점·결과·오답 다시 풀기까지 진행할 수 있습니다.

## 3. 실제 PC → 휴대폰 기록 이전

- [ ] PC에서 채점 기록·별표·완료한 학습을 만들고, 새 학습의 두 번째 문항까지 이동한 상태로 **나 → 기록 백업**을 누릅니다. JSON 파일을 보관합니다.
- [ ] 휴대폰에서 **나 → 백업 복원**으로 그 파일을 선택한 뒤 먼저 **취소**합니다. 휴대폰의 원래 기록이 바뀌지 않습니다.
- [ ] 다시 파일을 선택해 **이 기록으로 복원**을 누릅니다. 풀이·즐겨찾기·완료 기록·복습 일정과 진행 중인 학습 위치가 PC와 일치합니다.
- [ ] 휴대폰에서 **이어서 풀기**로 돌아와 채점하고 새로고침합니다. 새 기록이 유지됩니다.
- [ ] 휴대폰에서도 JSON 백업을 내려받아 파일 앱/다운로드 목록에서 찾을 수 있습니다. 기기 사이 자동 동기화는 없으며 이후 기록 이전에는 다시 백업·복원을 사용합니다.

## 4. 오프라인·직접 파일 실행

- [ ] 공개 사이트에서 하단의 **오프라인 저장 완료**를 확인한 뒤 네트워크를 끄고 새로고침합니다. 홈·검색·채점·과목별 해설을 사용할 수 있습니다. 원본 이미지·PDF 전체의 오프라인 저장은 보장하지 않습니다.
- [ ] 직접 파일 실행을 사용할 PC가 있다면 최신 앱으로 만든 ZIP 전체를 풀고 `index.html`을 엽니다. 검색·채점·백업·새로고침 후 기록을 확인합니다. 이 항목은 관리 환경에서 정책으로 차단되어 미확인입니다.

## 로컬 자동 재현

저장소 루트에서 실행합니다. 로컬 임시 서버를 자동으로 띄우고 종료하며, 별도의 브라우저 환경에 만든 테스트 기록만 사용합니다.

```sh
jaegyeong/.venv/bin/python jaegyeong/scripts/test_user_journey.py
```

결과 JSON과 화면 캡처는 Git에서 제외한 `jaegyeong/_artifacts/user-journey/`에 생깁니다. `TEST_ARTIFACT_DIR`로 다른 저장 위치를 지정할 수 있습니다. 서비스 워커를 격리하고 외부 폰트 요청을 막는 로컬 검사이므로 오프라인 저장과 CDN 폰트 확인은 위 실제 기기 점검에서 따로 수행합니다.
